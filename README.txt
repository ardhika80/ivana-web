LITTLE PIECES OF US — INTERACTIVE EDITION

MULAI
1. Ekstrak ZIP.
2. Buka index.html di Chrome atau browser lain.
3. Foto contoh akan menggunakan gambar cadangan online jika file foto lokal belum dimasukkan.

PERSONALISASI FOTO
Masukkan foto kalian ke folder assets dengan nama persis:
- photo-main.jpg
- photo-1.jpg
- photo-2.jpg
- photo-3.jpg

MUSIK
Masukkan file MP3 yang kamu miliki atau punya izin untuk digunakan sebagai:
assets/our-song.mp3
Musik tidak autoplay. Pengunjung menekan tombol "Play our song" untuk memulai.

EDIT TULISAN
Buka index.html untuk mengubah heading, teks, pilihan kuis, dan surat.
Buka script.js untuk mengubah cerita foto, jawaban kuis, dan interaksi.
Buka styles.css untuk mengubah warna, layout, animasi, dan ukuran.

INTERAKSI YANG SUDAH ADA
- Amplop pembuka dengan animasi buka.
- Tombol musik play/pause.
- Foto/catatan yang bisa diketuk untuk membuka cerita.
- Kartu rahasia yang bisa dibalik.
- Kuis romantis-lucu.
- Surat yang muncul baris demi baris saat masuk layar.
- Tombol kejutan dengan animasi hati.
- Progress bar saat scroll.
- Tombol mulai ulang.

CATATAN
- Isi teks saat ini adalah contoh; sesuaikan dengan kisah dan candaan kalian sendiri.
- Pastikan foto dan musik yang digunakan memang boleh dibagikan.
- Untuk membagikan lewat link, unggah folder ini ke layanan hosting statis seperti GitHub Pages atau Netlify.
- Uji di HP, termasuk tombol musik dan foto, sebelum mengirim link.
- Jika browser membuka file lokal dengan batasan tertentu, jalankan melalui server lokal atau hosting statis.
